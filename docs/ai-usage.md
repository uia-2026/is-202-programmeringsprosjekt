# KI-bruk i prosjektet

## Eksempler på AI-prompts som ble brukt

### 1. Planlegging av arkitektur
**Prompt:**
"Vi skal lage en ASP.NET Core MVC-applikasjon som samler inn data fra brukere via et skjema og viser det på en ny side. Prosjektet skal bruke et kart hvor brukeren velger posisjon. Hva er en enkel og god prosjektstruktur for dette?"

**Resultat:** KI foreslo MVC-strukturen med Controller, ViewModel og View, som vi adopterte.

---

### 2. Feilsøking i C#
**Prompt:**
"Jeg får denne feilen når jeg prøver å sende POST-data: 'NullReferenceException in controller'. Hvordan debugger jeg dette?"

**Resultat:** KI foreslo å sjekke om ViewModel-dataene var null før de ble brukt, noe som løste problemet.

### 3. Dokumentasjon
**Prompt:**
"Skriv en kort og tydelig README for et ASP.NET Core MVC-prosjekt. Inkluder seksjoner for drift, arkitektur, testing og KI-bruk."

**Resultat:** Brukt som grunnlag for vår README-struktur.

---

### 4. Hjelp med kartintegrasjon
**Prompt:**
"Hvordan kan jeg integrere et kart i en Razor-view som lar brukeren klikke og få koordinater?"

**Resultat:** Fikk forslag om biblioteker og kodeeksempler som hjalp med implementering.

---

## Verktøy som ble brukt
- GitHub Copilot
- Microsoft Copilot
- ChatGPT

## Konklusjon
KI var et verdifullt verktøy for planlegging, feilsøking og forståelse av oppgaven, men all implementasjon og endelige kode ble gjort av gruppen selv.
