# Dokumentasjon

Denne mappen inneholder all dokumentasjon for IS-202 Programmeringsprosjektet.

## Filer

- **README.md** – Denne filen, oversikt over dokumentasjonen
- **architecture.md** – Systemarkitektur, dataflyt og teknologi
- **ai-usage.md** – Konkrete eksempler på hvordan KI ble brukt i prosjektet

## Oversikt

Prosjektet er en ASP.NET Core MVC-applikasjon som:
- Samler inn data fra bruker via skjema
- Lar bruker velge kartposisjon
- Viser innsendt data på en ny side
- Kjøres i Docker-container på port 8080
